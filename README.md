App Router dan Pages Router adalah dua sistem routing dalam Next.js. Pages Router menggunakan sistem berbasis file di dalam folder pages, di mana setiap file otomatis menjadi rute URL dan menggunakan komponen layout secara global untuk satu halaman. Sementara itu, App Router menggunakan folder app berbasis React Server Components dengan struktur yang lebih modern. App Router mendukung layout bersarang, loading states, dan error handling secara spesifik di tiap sub-folder menggunakan file khusus seperti layout.tsx dan loading.tsx. Dari sisi performa, App Router secara default merender komponen di sisi server, sehingga ukuran JavaScript yang dikirim ke browser jauh lebih kecil dibanding Pages Router yang mayoritas merender di sisi klien. Singkatnya, App Router memberikan kontrol struktur folder yang lebih rapi, fleksibilitas layout tingkat lanjut, serta optimasi performa yang lebih modern untuk aplikasi skala besar.
